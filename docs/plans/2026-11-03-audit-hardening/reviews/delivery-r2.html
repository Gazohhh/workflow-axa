What was agreed

What was asked

Fix the defects that the owner's audit found in workflow-axa 2.8.0-rc.1. The goal is fewer unauthorized actions, clearer recovery and less repeated work. The goal is not more instructions or a larger test count.

This is a separate task. It fixes defects in the package that the task 2026-11-02-modular-engineering-workflow built.

Agreed behavior

Edits and git writes get permission only from the current task's approval, with the user's real words. The gate sees more tools and more shell writes.

Record writes become safe against interruption and a second writer. A stop ends implementation, and each unfinished state has one route. Baselines compare test IDs and stop being reused when their inputs change.

Report wording advice keeps the meaning and runs before the file is written. A small change uses fewer agents. The tests pass on other machines. One generated summary replaces the contradicting counts, and a release package comes from an include list.

Not included: application repositories, global settings, permission changes and automatic commits.

Your answers D1 to D5 are part of it. Approval needs the Approval line plus your real words. Small changes use the small route. The project gets an MIT license and a release tool now. T9 uses at most 8 live Claude runs plus useful Codex runs.
