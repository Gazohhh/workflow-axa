# Recipe on resume and when the pick changes

Read this on resume, and when later evidence or the owner's correction changes the recipe pick. The router's [SKILL.md](SKILL.md) §3 owns the pick itself.

1. On resume, reconcile the recorded pick with the current scope and show it again. An unchanged scope keeps its pick and question history. An older task with no recorded pick: infer it from the records and code; a missing line alone is not uncertainty. A status-only resume stays read-only.
2. When later evidence or the owner's correction changes the pick, show the new line with the evidence, keep the work done and the question history, and add only the steps the new recipe adds. A changed pick grants no new authority; changed scope follows the revision and approval rules.
